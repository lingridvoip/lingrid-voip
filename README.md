# Lingrid VoIP

Multilingual landing page for Lingrid VoIP, with Arabic, English and French support.

## Website files

The complete static website is in `dist/`. It includes animated international voice routes, termination rates, SMS OTP services, partner logos and an automated FAQ chat with WhatsApp handoff.

## Local preview

Serve `dist/` with any static HTTP server. No build step is required.
